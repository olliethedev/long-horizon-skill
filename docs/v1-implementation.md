# V1 implementation

V1 implements the owner's authorization to build and publish the project. The review baseline is `62fec70`; accepted scope is [v1-spec.md](v1-spec.md).

The runtime bundle now includes bounded read-only history search/pagination, content-versioned source pages, explicit evidence-time and correction guidance, editable responsibility/action/evidence/handoff templates, and an Impulse assignment definition. Source records remain authoritative; no database or mandatory index is introduced.

The public CLI tests found and fixed path/symlink exposure, oversized-record coverage gaps, Unicode excerpt positioning, and unreadable-directory coverage. These behavioral seams use actual temporary files and subprocess calls. Strict typing and copied-bundle checks run alongside them.

Both the [initial](../evals/results/impulse-v1/result.json) and [final real-clock Impulse exercise](../evals/results/impulse-v1-final/result.json) passed continuation after deliberate process failure and a daemon restart, stable request-ID replay, fresh-process recovery, and disabling future work at bounded completion. The final run also retained [cleanup verification](../evals/results/impulse-v1-final/cleanup.json), with no cleanup errors and its isolated daemon stopped. These used their own state directories and scripts, rather than a live product or model-driven pilot.

The installed task template validated against the real Impulse CLI. The copied-bundle test resolves every local runtime reference and executes the helper outside this repository. Official skill metadata validation passes. Runtime helpers use Python 3.11+ standard-library facilities; strict mypy covers the helper and maintained evaluation tooling. Linux is the verified platform.

Both independent review axes found a timestamp-preserving correction could evade the original metadata-only search cursor. A public CLI regression reproduced the omitted correction before the fix. Search now includes source-content hashes and checks the inventory again after navigation; the regression passes. This reads supported source bytes to validate a cursor, with bounded memory and output. It does not lock history against concurrent writers. Paged source reads also use content hashes. The helper provides literal search and bounded source access, not semantic retrieval or proof that no differently named prior action exists.

The [independent dense-history comparison](../evals/results/v1-recall/REPORT.md) completed eight sessions across revenue experiments, weekly product improvement, large-export feedback, and post-PR monitoring. Both arms satisfied 20/20 source-based criteria across four decisions. The skill reduced captured command output by 79.7%, with no results above 20,000 bytes versus ten for the baseline. It used more commands, total reported input tokens, and elapsed time. This is useful evidence about retrieval behavior, with no demonstrated decision-quality or total-token advantage.

Each domain contained roughly 2.49 MB of seeded history. Generated background IDs allowed easier pruning than an organic archive; both prompts also explicitly requested source citations and unknown-date preservation. The eight infrastructure attempts preceding the successful matrix are retained separately. The study is one session per arm/domain, and its read-only decisions do not prove autonomous operation over months. The historical 55-session lifecycle study and the real Impulse script exercise remain distinct evidence.
