# Pause for resolvable blockers

When progress requires something the owner can unblock, such as analytics access, pause the task, preserve its context, and provide an actionable notification identifying the missing prerequisite. The owner fixes the blocker and explicitly resumes the task; restoring the prerequisite alone does not restart it. The user rejected automatic restoration checks as unnecessary complexity.

Normal scheduled waits for expected conditions, such as an observation window or cooldown, remain available. Reserve impossible termination for evidence that no viable route exists within the agreed constraints, so missing access or temporarily unavailable data does not erase a still-useful responsibility. On an explicit resume, verify the prerequisite and current instructions before continuing.
