# Agree reporting at setup and notify on consequential transitions

Agree a report cadence and destination during the responsibility's setup interview. Send routine progress digests on that cadence, and immediate notices when the task pauses, terminates, or needs an owner decision. Other runs update the durable history. The user accepted this policy September 8, 2026; a weekly digest was an example, not a universal schedule.

This keeps the owner informed about progress and consequential changes without requiring a message after every run. The task's setup establishes the actual destination and permission to use it. Delivery mechanisms remain to be prototyped; this design decision does not select a messaging integration or authorize sending messages from the current project.
