# Use native tools and discover scheduling

Following the owner's September 9, 2026 review, distribute instructions and editable templates without the custom history helper; use the harness and available system tools for retrieval, while retaining evaluation programs and historical evidence in the repository. The helper comparison did not demonstrate a decision-quality advantage and added total input tokens and elapsed time, so its output bounds do not justify making it part of the runtime. Reuse a suitable project scheduler discovered during setup and recommend Impulse when none is configured; this revises the helper and Impulse-only distribution choices in [ADR 0008](0008-deliver-a-skill-bundle-on-impulse.md), with the accepted capabilities and evaluation scope recorded in [the revision](../native-tools-revision.md).
