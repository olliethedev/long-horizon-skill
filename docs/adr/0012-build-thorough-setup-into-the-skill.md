# Build thorough setup into the skill

The long-horizon skill conducts a thorough, task-specific setup interview before autonomous operation, resolving the details that determine what the agent should pursue, what it may do, and how it should evaluate and coordinate its work. The owner explicitly prefers this depth because responsibilities can operate autonomously for months; a minimal intake that leaves important choices implicit is insufficient. Use the one-question-at-a-time grilling approach within the skill, preserve answers in the durable brief, and reuse decisions already established through project context or a prior interview, so a separate `grill-me` invocation is optional.

The owner-approved refinement requires a review of discovered tools and workflows even when the agent considers discovery complete, explicit artifact and owner-input policies, and verified essential capabilities or accepted adequate fallbacks. Optional autonomous-run limits are settled before activation rather than blocking ordinary setup investigation.

Prepare and validate the concrete setup before showing the final summary. The owner explicitly requested one final activation confirmation after that summary; only then enable and verify scheduled work. This gate applies to new responsibilities, while standing permissions continue across ordinary runs of established work. The authoritative procedure is [setup.md](../../skills/long-horizon/references/setup.md).
