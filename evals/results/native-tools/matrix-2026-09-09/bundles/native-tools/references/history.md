# Retrieve before choosing work

Use the harness's search, glob, and file-reading tools or available system utilities such as ripgrep. Choose tools and read sizes appropriate to the archive; this skill supplies no retrieval program or required index. Keep searches within the authorized product workspace, including any linked evidence whose location is authorized.

Start with the brief and current handoff. Locate relevant subjects, aliases, action identities, and source references, then inspect the original attempts, actual outcomes, and later interpretations. For a large archive, search likely subjects or paths before expanding. A small archive may be practical to read directly. Follow renamed interventions and source IDs into later references even when the handoff calls the matter settled.

Use the dates recorded in the evidence to reconstruct chronology. Event/request time, deployment time, observation window, and retrieval time mean different things; see [evidence.md](evidence.md). Filesystem modification time or date-like filenames can help navigate, but cannot establish when a request occurred or which correction applies. A newer source for a different cohort or version does not replace the relevant older observation.

Inspect enough surrounding context to interpret each match. When results are truncated, paginated, filtered, or omit a format, follow up before claiming the relevant history is exhausted. No matches for one phrase does not establish that an intervention never happened. Broaden through aliases, linked records, or another available tool as needed. An optional index is navigation into retained sources; rebuild or bypass it when missing or stale.

Before a consequential decision, retain the relevant original attempt, actual outcome, latest applicable correction, and why their conditions match or differ today. Cite source paths and stable identities so a later session can inspect the reasoning. If evidence changes during the investigation, re-read affected sources and reconcile the changes; use available revision information when helpful. Preserve the original records when updating conclusions.
