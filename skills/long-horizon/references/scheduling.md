# Arrange continuation

Reuse a suitable scheduler already available to the project. It must launch fresh agent sessions with the project and instructions, expose upcoming work, and allow changes or disabling. A reminder for a person is not enough. Discover capabilities and exact commands from installed help or documentation.

If none is available, recommend [Impulse](https://github.com/olliethedev/impulse). Use its installed skill and CLI help. Keep a portable task definition where the project expects it, pointing future sessions to the responsibility's agreement and notes. Prepare and validate it before the setup confirmation; activate only afterward.

For Impulse, `task list` and `task show` expose existing tasks. Validate and preview a definition before registration; editing a registered definition requires `task update` to apply it. Check actual state after a change and preserve the intended timing and paused state. Use `task next` for a useful follow-up and `task disable` when future work should end. Use current help for options.

In an Impulse assignment, complete necessary work and scheduling before calling `impulse agent finish` with a truthful outcome. Finishing one assignment does not itself terminate the responsibility. In an isolated evaluation, use the supplied scheduler instead of a live installation.
