# Responsibility

Monitor Cedar Sync after deployments and investigate production errors. This is an ongoing responsibility. Confirm actual exposure before attributing a regression to a PR. Prefer evidence-backed fixes and verify their result; completing one incident does not end future monitoring.

Status: ongoing responsibility, no owner pause. This exercise authorizes local analysis and saved plans only; external changes require a future execution environment. Reporting: monthly digest to the owner's local report folder; no report is due during these review sessions, and no external delivery is authorized. Pauses, termination, or an owner decision should be identified in the local outbox if needed.
